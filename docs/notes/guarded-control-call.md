## Exact contract

`GuardedControlCall.body` contains the two actual local initializers and
the single lowered guarded command: exactly three top-level statements.
There are **no observer assignments**. The existing observer inout parameter
remains, passes through unchanged, and is still actually copied back. The
body equals the committed prefix's empty-suffix instance; its Index is
actually built from that body. Index.build success is not global validity.

For arbitrary source hdr/metadata/route, observer Value, original Run and
continuation K, `source_steps` proves the real machine starts with
`block RewriteBody args :: K` and ends with exactly K, no fault, and:

```text
original Run with frame := returnedFrame originalCaller
  independentPolicyHdr independentPolicyMetadata originalObserver
```

The policy values are projections at literal top-level Store slots after
the independent named Snapshot policy. They do not use authored field
accessors, command denotation or interpreter outputs. The theorem composes
actual prefix entry/body execution, **one empty-statements pop**, then the
actual successful return. K is not executed or assumed to terminate.

`call_correct` specializes K to empty and uses Finishes.sound to establish
actual `callBlock` returns `.ok ()` with that exact Run. This is a completed
call theorem, not merely a finite execution prefix. `changes_only_vars`,
`result_lookup` and `preserves_outside` expose exact original caller scope/
action state, the three returned roots, and all other caller names. Thus
source_route stays unchanged; caller scratch/unrelated remain their old
values, rather than receiving callee scratch19/unrelated165. Packet, emitter,
installed entries, externs, visits and every Index component remain exact.

The necessary operational premises are still explicit: the original Run's
Index is this real body-bearing Index, the caller has no action layers, and
its four actual argument reads return the supplied source/observer values.
The observer can be any Value; no implicit typing assumption is introduced.
There is no premise asserting whole-call correctness and no replacement
executor, binder, return loop, AST or source semantics.

Confidence is high in this bounded composition, medium in the fixed
four-parameter signature as a long-term public API. Revisit abstraction for
a second distinct call client. Caller construction/global validation,
parsing, route lookup, checksum repair, architecture drop/forward fate,
observer encoding, arbitrary actions/lvalues and fault unwinding remain
unproved here. This profile does not execute the existing 17 observer
assignments or prove the complete packet wrapper.

Syntax is independently constructed from tracked declaration helpers, literal

block, parameters/arguments and nominal declarations. It does not obtain its
expected body by slicing the candidate's own body. A paired wrong exported

Retained negative controls cover four copy-in root aliases; selective Metadata,
